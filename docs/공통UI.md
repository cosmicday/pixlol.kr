## ★★ dogu.gg 공통 UI 적용 (2026-08-22 · 커밋·배포됨)

`DOGU_UI_PLAN.md` 2단계의 pixlol 몫. **`public/dogu-ui.css` · `public/dogu-header.js` 는 복사본이라
여기서 고치지 말 것** (원본 `dogu_template/dogu-ui/`, 손대기 전 5곳 md5 확인 — `DOGU_UI.md` 11-0). 사양은 `dogu_template/dogu-ui/DOGU_UI.md`. 데이터 로직은 안 건드렸다.

- **`#hero` 는 `main` 밖(헤더와 `main` 사이)에 있다.** `.main-search-section` 안에 두면 모바일 좌우 28px 패딩 때문에
  검색창이 552px 로 좁아져 다른 사이트와 어긋났다 (실측 후 옮김). 홈이 아닐 땐 공통 CSS 가 `body.dogu-home` 기준으로 숨기므로
  `hideAllContainers()`/`goLobby()` 의 `setHome()` 호출이 곧 히어로 표시 조건이다

- **헤더·히어로 검색창·푸터는 전부 `app.js` 의 `mountDoguUI()` 가 그린다** (`index.html` 에 마크업 없음).
  탭은 `DOGU_NAV` 한 표다 (2026-08-27 부터 하위 메뉴 `sub` 와 `hidden` 이 붙었다 — 위 "헤더 메뉴 개편" 절).
  비공개 탭(장인랭킹·클래식)을 되살릴 땐 여기 줄을 더한다
- **★★ 홈에서는 ⌂ 에 밑줄이 켜진다 (2026-08-27).** 예전엔 홈에서 `전적검색` 탭에 밑줄이 남아 **다른 4개 사이트(홈에서 아무 데도 안 켜짐)와 어긋났다.**
  공통 CSS 가 `body.dogu-home .dogu-nav-home` 으로 켜므로 **5개 사이트 전부 자동**이고 사이트 JS 는 손댈 게 없다 (원본 수정 + sync).
  pixlol 쪽은 탭을 끄는 일만 한다 — `mountHeader` 의 `active: false` · `goLobby()` 의 `setActiveNav(null)` ·
  `doguRoute()` 에서 **전적검색 탭만 setActiveNav 를 건너뛴다**(그 탭의 go() 가 goLobby 라 홈으로 간다).
  **★ 그 대신 라우터 `/summoner` 분기에 `setActiveNav('nav-search')` 를 새로 넣어야 했다** — 예전엔 mountHeader 의 기본 active 가 켜 주던 자리다 (/ranking 과 같은 함정).
  폰(≤768px)은 ⌂ 를 숨기므로 홈에서 밑줄이 아무 데도 없다 (실측 390px: 넘침 0)
- **★ 라우터 연결 두 곳**: `hideAllContainers()` 가 `DoguUI.setHome(false)`, `goLobby()`/진입부 `/` 가
  `setHome(true)`. `setActiveNav('nav-xxx')` 가 `DoguUI.setActiveNav('xxx')` + `document.title`
  (고정 `PIXLOL.KR: 리그오브레전드` — index.html `<title>` 과 같은 값) 을 맡는다. 옛 `.bg-solid` · 햄버거(`toggleMobileMenu`) 는 지웠다
- **★ 검색 입력 id 는 `dogu-search-input`** (옛 `summoner-input` 21곳 치환). `search-btn.click()` 9곳은
  `executeSearch()` 로. 1단 헤더 검색창도 값을 히어로 칸에 넣고 `executeSearch()` 를 탄다 —
  **executeSearch 가 그 칸을 읽는 규약**이라 헤더 검색을 따로 만들지 않았다
- 즐겨찾기/최근은 `getFavorites/removeFavorite/getRecents/removeRecentSearch` 를 공통 드롭다운에
  그대로 꽂았다. `renderDropdownList()` 는 `DoguUI.refreshDropdown()` 한 줄이다
- 자동완성(`#autocomplete-dropdown`)은 pixlol 고유라 남기고 마운트 뒤 `.dogu-search-wrapper` 안으로
  옮긴다 (`.ac-dropdown` 이 옛 `.search-dropdown` 의 자리 속성을 물려받았다)
- **★★ CSS 주석에 `.nav-*/` 처럼 `*/` 가 들어가면 주석이 거기서 닫혀 뒤 규칙이 통째로 죽는다.**
  실제로 한 번 그랬다 (홈 위젯이 가로로 눕는 증상) — 선택자 이름을 주석에 적을 땐 `*` 뒤에 `/` 금지
- **★★ 폰 배경 초점은 `--dogu-bg-pos: 75% center` 다 (2026-08-25).** 룰루 스플래시(1215x717)는
  **인물이 가로 62~90%** 에 있는데, 폰은 세로가 길어 `cover` 가 세로에 맞추면서 가로를 크게 잘라낸다 —
  기본값 `center` 로는 **원본의 36~64% 구간만** 보여 룰루가 화면 밖이었다 (배경이 흐릿한 보라 덩어리로만 보였다).
  75% 면 폰 세 폭(360·390·414) 모두 **55~82%** 가 보여 얼굴이 들어온다. 768px 은 42~86%.
  **데스크톱은 안 건드린다** — 가로가 넓어 4~96% 가 보이므로 인물이 이미 나온다.
  **★ 이건 공통 CSS 가 사이트더러 덮어쓰라고 열어 둔 변수라 규칙 위반이 아니다**
  (dogu-ui.css 주석: "일러스트마다 인물 위치가 달라 사이트가 덮어쓴다"). `.dogu-*` 를 건드리는 게 아니다
- **일부러 안 맞춘 것**: 로고·⌂·푸터 홈 링크는 `https://pixlol.kr` 가 아니라 `/` 다 (같은 곳인데
  절대 주소면 로컬에서 프로덕션으로 튄다). `body` 글자색은 공통 `#e6eefb` 가 이긴다 (옛 `#fff`).
  오버레이 색은 옛 값 `11,11,20` 을 변수로 넘겼다 (er 남색 `6,11,26` 아님)
- **게임 스위처 아이콘은 공통 파일이 그린다** — `mountHeader` 에 `iconBase: '/'` 만 넘긴다 (`public/header_<key>.png` 5장).
  한때 `app.js` 의 `decorateSwitcherIcons()` 가 DOM 을 덧칠했는데 아이콘 크기·간격이 다른 사이트와 어긋나서 뺐다 (2026-08-22).
  **`.dogu-*` 안쪽을 사이트 JS 로 덧칠하지 말 것**
- 실측(헤드리스 1400/390): 홈↔랭킹 오버레이 0.52↔0.8 전환 · 폰 넘침 0 · 전적 갱신 버튼은
  `.refresh-btn` 으로 분리(옛 `.search-btn` 그라데이션을 빌려 쓰고 있었다)

## ★★ 헤더 메뉴 개편 (2026-08-27) — 도감 하위 메뉴 · e스포츠 · 방송

**지금 헤더는 이렇다** (같은 날 저녁에 전적검색이 빠지고 패치노트가 들어와 일곱 칸이다):

```
랭킹 · 통계 · 패치노트▾ · 도감▾ · 신화상점 · e스포츠 · 방송
              └ 본서버   └ 챔피언 · 아이템 · 룬 · 소환사 주문
                PBE
```

옛 「챔피언」 탭과 도감 안 탭 3개가 **도감 하위 4개**로 합쳐졌다 (사용자 요청).

- **★★ 하위 메뉴는 공통 파일 기능이다** — `nav[].sub = [{key,label,href}]`. 원본(`dogu_template/dogu-ui/`)을 고쳐 5곳에 sync 했다.
  **`sub` 를 안 넘기는 사이트는 마크업이 한 글자도 안 바뀐다** (er·maple·loa·tft 무영향, 실측 확인)
- **★ 도감 부모는 `href` 가 없다 → 링크가 아니라 `<span>` 이라 눌러도 아무 데도 안 간다** (사용자 결정).
  공통 JS 가 `span.dogu-nav-parent` 의 클릭을 삼킨다 — 안 그러면 **폰에서 라벨을 누르는 것만으로 메뉴가 닫힌다**
- **★★ `.dogu-nav` 가 `overflow-x: auto` 라 드롭다운이 그 안에서 잘린다.** 하위 메뉴가 있을 때만
  `.dogu-nav.has-sub { overflow: visible }` 로 푼다 (안 쓰는 사이트는 네비 가로 스크롤 그대로).
  pixlol 네비는 일곱 칸이어도 **457px** 라 769px 폭에서도 안 넘친다 (실측)
- **★ `DOGU_NAV_FLAT` 을 같이 본다** — `doguRoute()`·`setActiveNav()` 가 `DOGU_NAV` 만 훑으면 하위 4개를 못 찾는다.
  활성 표시는 공통 `setActiveNav` 가 **하위가 켜지면 부모도 같이** 켠다
- **★ 페이지 안 4칸 줄은 `codexTabsHtml()` 하나다** (도감·챔피언 두 페이지가 같은 줄을 쓴다, 사용자 결정).
  클릭은 **위임 리스너 하나**(`goCodexTab`)가 받고 **이력은 덮어쓴다**(replaceState) — 주소 규칙 그대로다.
  헤더 드롭다운으로 들어오는 건 메뉴 진입이라 각 `show*` 가 pushState 한다
- **★ 라우터를 네 곳 고쳤다** — 진입부·popstate 각각의 `/codex`(탭별 navId = `codexNavId()`)와 `/esports`·`/broadcast`.
  **한쪽만 고치면 "주소를 치면 되는데 뒤로가기로 오면 안 되는" 상태**가 되는 그 함정
- **★ 도감 주소가 이제 항상 탭까지 담는다** (`/codex` 로 들어와도 `/codex/item` 으로). 옛 `/codex` 링크는 그대로 열린다
- **★ `codexLastPick` 을 모듈 자리로 뺐다** — 탭이 페이지가 되면서 `showCodex` 안의 지역 표는 매번 비어,
  "탭으로 돌아오면 보던 걸 다시 연다" 가 죽는다
- **★★ 폰 햄버거 메뉴가 원래 반투명이라 뒤 페이지 글자와 겹쳐 읽혔다** (개편 전부터 그랬다 — 옛 판 스크린샷으로 확인).
  항목이 6 → 11개로 늘며 심해져서, 공통 CSS 에 **`--dogu-gnb-panel`** 변수를 뚫고 pixlol 이 `#16112a` 로 덮는다
  (기본값은 예전 반투명이라 다른 사이트는 그대로). **`--dogu-bg-pos` 처럼 사이트가 덮으라고 연 변수다**
- **★ e스포츠·방송은 준비 중 페이지다** — `showComingPage()` 하나가 제목 + 공통 `comingSoonHtml()` 을 그린다.
  상자는 `index.html` 의 `#esports-container`·`#broadcast-container`(`.page-container.dogu-doc`).
  진짜 내용을 채울 땐 그 함수 대신 각자 `show*` 를 쓰면 된다

**같은 날 또 이어서 — 전적검색 탭 제거 · 패치노트 메뉴 신설:**

헤더가 `랭킹 · 통계 · **패치노트▾**(본서버/PBE) · 도감▾ · 신화상점 · e스포츠 · 방송` 이 됐다.

- **★★ 전적검색 탭은 `hidden: true` 로 헤더에서만 뺐다 — `DOGU_NAV` 에서 지우면 안 된다.**
  로고·⌂ 의 `href '/'` 와 `/summoner` 의 `setActiveNav('nav-search')` 가 그 줄을 찾는다.
  지우면 `doguRoute` 의 폴백(`|| DOGU_NAV[0]`)이 걸려 **로고를 눌렀을 때 랭킹으로 간다.**
  `mountHeader` 로 넘길 때만 `filter(n => !n.hidden)` 로 거른다 (홈은 로고·⌂ 로 간다 — 실측 확인)
- **패치노트는 도감과 같은 꼴의 부모다** (href 없음 → 눌러도 안 움직이고 하위만 연다).
  `/patch/live` · `/patch/pbe` 이고 `/patch` 는 본서버로 간다. 페이지 안 2칸 줄은 `patchTabsHtml()` —
  **도감과 같은 `.codex-tabs` 클래스**를 쓴다 (모양이 같아야 메뉴를 옮겨도 안 튄다)
- **★★ 본문은 안 들여온다 — 목록만이다.** 제목을 누르면 공식 페이지 / x.com 으로 나간다.
  공식 패치노트에는 상향·하향 마커가 없어서 옮겨 오면 `10 → 8` 의 방향을 우리가 추측하게 된다
  (`dogu_er` 의 패치 페이지가 같은 이유로 목록만 싣는다 — 그쪽 주석에 근거가 있다)
- **서버 `/api/patch-notes` 를 넓혔다** (수집 방식은 그대로다):
  · `official` 5건 → **목록 전부(172건)** + `thumb` · `desc` · `version` 필드 (`__NEXT_DATA__` 에 다 있다 — 요청은 그대로 한 번이다)
  · **`PATCH_LIST_MAX` 200 — 공식 목록이 주는 172건이 전부 담긴다** (9.1 / 2019-01 까지. 2026-08-27 실측).
    그 페이지의 「더 보기」 버튼은 `pager.more.action.url` 이 **`#`** 이라 **서버에 더 물어볼 곳이 없다** — 172가 원본의 끝이다
  · **PBE 는 `pbenotes` 창고에서 나간다 (2026-08-27 신설).** RSS 는 최근 20글만 줘서 그것만 쓰면 8건이 한계다 —
    30분마다 읽는 김에 `savePbeNotes()` 가 upsert 하고, 화면에는 `loadPbeNotes()` 가 창고를 날짜순으로 준다.
    **창고가 비었거나 조회가 실패하면 RSS 값을 그대로 쓴다** (한 줄이라도 나가게)
